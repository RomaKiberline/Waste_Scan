# Waste_Scan
Розпізнавання та класифікація побутових відходів за фотографіями.

## Мета
Створити сервіс, у якому користувач завантажує фотографію
предмета й отримує передбачену категорію відходів.

## Датасет
Garbage Classification Dataset — Kaggle.

## Команда

- Чупирчук Роман — розробка й навчання нейромережі.
- Ходак Ярослав — Streamlit-застосунок та інтеграція моделі.
